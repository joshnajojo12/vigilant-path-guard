1. Secret Code & Voice Trigger

User can enter a secret code or say it aloud 3 times (e.g., “Amma Amma Amma”).

The system continuously listens using the microphone and activates emergency detection when the code is detected correctly 3 times.

Include adjustable sensitivity for voice recognition to avoid false triggers.

2. Multi-Sensor Emergency Detection

Confirm danger if 2 or more signals occur within 5 seconds:

Webcam: detect sudden motion and light changes

Microphone: loud sounds, panic voice detection using ML model (TensorFlow.js / Hugging Face)

Accelerometer/Gyroscope: detect running, falling, or unusual movements using ML

Smooth readings with averaging to reduce false positives.

Adjustable thresholds for all sensors.

3. Live Location & WhatsApp Alerts

Continuously track browser GPS location.

Show Google Maps iframe and clickable link in the UI and alert log.

Send WhatsApp message via Twilio to the configured phone number:
"🚨 Emergency detected! User is in danger at https://maps.google.com/?q=<latitude>,<longitude>"

Ensure automatic retry if the first WhatsApp attempt fails.

Simulate alerts visually if Twilio not configured.

4. Safe Path & Dangerous Area Prediction

Predict safest path to a destination using:

Traffic density

Crowded areas

Nearby shops or open spaces

Lighted/low-light areas

Flag dangerous areas based on historical crime data or user reports.

Update route dynamically to avoid dangerous zones.

5. Buddy System

Connect users nearby in real-time via app

Allow users to check profiles and send quick SOS notifications to trusted contacts nearby

6. Frontend (React/JS + CSS)

Secret code input & voice detection

Live webcam overlay (motion + light)

Sound level, motion, and light graphs

Status indicator: SAFE ✅ / ALERT 🚨

Map iframe showing current location

Alert log with timestamp, trigger reason, and Google Maps link

Phone input + test WhatsApp button

7. Backend (Node.js + Express)

/send-alert endpoint:

Accept phone number + location

Send WhatsApp alert via Twilio API

Return success/error response

Ensure location is accurately fetched before sending the message

Include rate limiting and cooldown to prevent multiple alerts

8. Accuracy & Reliability

Use ML models for panic voice detection and movement classification

Multi-sensor confirmation ensures high accuracy, avoids false positives

Adjustable thresholds for code, sound, motion, and light detection
